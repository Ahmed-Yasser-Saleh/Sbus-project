## 1. شكل المشروع

```
SBus.sln
├─ src/SBus.Core     ← الكيانات، الداتابيز (EF Core + Npgsql)، منطق الحجز
├─ src/SBus.Web      ← Razor Pages: صفحات الراكب + لوحة المكتب
└─ tests/SBus.Tests  ← اختبارات منطق الحجز
```

- ‎.NET 8، PostgreSQL لوكال، داتابيز جديدة اسمها `sbus`.
- الأوقات تتخزن UTC وتتعرض بتوقيت القاهرة (`Africa/Cairo`، فيه توقيت صيفي).
- مفيش Hangfire: تنظيف الحجوزات المنتهية بـ `BackgroundService` بسيط كل دقيقة.

## 2. الجداول

### الإعدادات (المكتب بيظبطها مرة واحدة)

| الجدول | الأعمدة المهمة | ملاحظة |
|---|---|---|
| `Stops` | Name, City, Notes | كل أماكن الركوب والنزول |
| `RouteStops` | Direction, StopId, Order, MinutesFromStart | ترتيب المحطات في كل اتجاه، والوقت التقريبي من أول الرحلة عشان التذكرة تقول "الأتوبيس عندك حوالي 6:40" |
| `SeatLayouts` | Name, Rows, Columns | شكل الميني باص |
| `LayoutSeats` | LayoutId, SeatNumber, Row, Column | كل كرسي ومكانه — نفس الأرقام اللي على الكراسي الحقيقية |
| `Buses` | PlateNumber, LayoutId, IsActive | |
| `Drivers` | Name, Phone, IsActive | |
| `Schedules` | Direction, DepartureTime, Price, DefaultBusId, DefaultDriverId, IsActive | المواعيد الثابتة اليومية |

### الشغل اليومي

| الجدول | الأعمدة المهمة | ملاحظة |
|---|---|---|
| `Trips` | ScheduleId, Date, DepartureAtUtc, BusId, DriverId, Price, Status | رحلة فعلية في يوم معين. بتتولد من `Schedules` لأيام قدام. unique على (ScheduleId, Date). السعر بيتنسخ وقت التوليد عشان تغيير السعر ما يغيرش رحلات اتحجزت |
| `Bookings` | TripId, PublicToken, PassengerName, Phone, PickupStopId, DropoffStopId, Amount, Status, Source, HoldExpiresAtUtc, ReceiptPath, CreatedAtUtc, ConfirmedAtUtc, CancelledAtUtc, CancelledBy | `PublicToken` = الكود السري اللي في لينك التذكرة. `Source` = أونلاين أو مكتب |
| `BookingSeats` | BookingId, TripId, SeatNumber, IsActive | **unique جزئي على (TripId, SeatNumber) WHERE IsActive** — ده اللي بيمنع الحجز المزدوج. عند الإلغاء أو الانتهاء `IsActive = false` فالكرسي يفضى والتاريخ يفضل موجود |

مستخدمين المكتب: ASP.NET Core Identity.

### حالات الحجز

```
HoldPendingPayment ──رفع صورة التحويل──► AwaitingConfirmation ──المكتب أكّد──► Confirmed
       │                                        │                                 │
   عدّت المدة                             المكتب رفض                        إلغاء (راكب/مكتب)
       ▼                                        ▼                                 ▼
    Expired                                 Rejected                          Cancelled
```

- الكرسي محجوز في كل الحالات ما عدا Expired و Rejected و Cancelled.
- بعد رفع صورة التحويل الحجز **ما ينتهيش لوحده** — الراكب دفع، فالقرار للمكتب.
- حجز المكتب للي بيتصل بيبدأ Confirmed على طول.

## 3. الشاشات

### الراكب (من غير تسجيل دخول)

1. **الرئيسية** — يختار الاتجاه واليوم، ويشوف الرحلات وعدد الكراسي الفاضية في كل واحدة.
2. **الرحلة** — خريطة الكراسي (فاضي / محجوز / اختيارك)، الاسم، الرقم، مكان الركوب والنزول.
3. **الدفع** — رقم إنستا باي بتاع الشركة، المبلغ، عدّاد المدة الباقية، رفع صورة التحويل.
4. **التذكرة** `/t/{token}` — الحالة، الكراسي، الرحلة، الوقت التقريبي عند محطته، رقم السواق (يظهر بس لما الحجز يتأكد)، زرار إلغاء.

### المكتب (بتسجيل دخول)

1. **النهارده** — رحلات اليوم، وعدد المحجوز في كل واحدة.
2. **مراجعة الدفع** — الحجوزات المستنية تأكيد، صورة التحويل، زرار تأكيد / رفض.
3. **تفاصيل الرحلة** — خريطة الكراسي، كشف الركاب (اسم، رقم، كرسي، محطة)، حجز لحد بيتصل، إلغاء، تغيير الأتوبيس أو السواق.
4. **الإعدادات** — المحطات وترتيبها، المواعيد والأسعار، الأتوبيسات وشكل الكراسي، السواقين.

## 4. ترتيب الشغل

| # | الخطوة | النتيجة |
|---|---|---|
| 1 | المشروع + الجداول + أول migration + بيانات ديمو | داتابيز فيها محطات ومواعيد وأتوبيسات ورحلات أسبوع قدام |
| 2 | منطق الحجز + الاختبارات | حجز، تأكيد، رفض، إلغاء، انتهاء المدة. اختبار إن اتنين بيحجزوا نفس الكرسي في نفس اللحظة واحد بس ينجح |
| 3 | صفحات الراكب | حجز كامل من الموبايل لحد صفحة التذكرة |
| 4 | لوحة المكتب | تأكيد الدفع، الحجز بالتليفون، كشف الركاب، الإعدادات |
| 5 | تشطيب الديمو | RTL، شكل مناسب للموبايل، بيانات ديمو واقعية |

بعد كل خطوة: أوريك النتيجة، ونكمل لما توافق.

## 5. أسئلة مفتوحة (ليها افتراض، غيّره لو مختلف)

| السؤال | الافتراض |
|---|---|
| الراكب يحجز كام كرسي في المرة؟ | لحد 4 كراسي في حجز واحد |
| مدة حجز الكرسي قبل رفع التحويل | 15 دقيقة |
| آخر وقت الراكب يقدر يلغي فيه بنفسه | لحد ساعتين قبل الرحلة، وبعدها يكلم المكتب |
| الحجز بيفتح قبل الرحلة بقد إيه | 7 أيام |
| أسماء المحطات والمواعيد والأسعار | بيانات وهمية للديمو لحد ما تجيب الحقيقية |
| شكل الميني باص | 14 راكب (تويوتا هايس) لحد ما تصوّر الكراسي الحقيقية |
| رقم إنستا باي اللي يظهر للراكب | رقم وهمي في الإعدادات |
| صور التحويل | تتخزن في فولدر على الجهاز **برا** `wwwroot`، عشان محدش يفتحها من غير تسجيل دخول المكتب |
