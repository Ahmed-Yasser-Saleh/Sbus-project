# S Bus — قرارات الـ MVP

آخر تحديث: 2026-10-08

## الهدف

ديمو نعرضه على S Bus: حجز كرسي أونلاين بدل التليفون.

## البيزنس

| # | الموضوع | القرار |
|---|---|---|
| 1 | الزبون | S Bus — شركة واحدة. ديمو للعرض عليهم. |
| 2 | الخطوط | خط واحد في الاتجاهين: القاهرة ← السويس، والسويس ← القاهرة. لكل اتجاه نقطة انطلاق ثابتة ونقطة وصول ثابتة، والأتوبيس بيقف في نقط على الطريق يركّب وينزّل. |
| 2a | الكرسي والمحطات | الراكب يختار مكان ركوبه ونزوله من قايمة ثابتة، والكرسي محجوز للرحلة كلها. الكرسي اللي صاحبه نزل في نص الطريق ما يتباعش تاني في نفس الرحلة. |
| 3 | السعر | سعر ثابت للرحلة، مهما كان مكان الركوب أو النزول. |
| 4 | المواعيد والأتوبيسات | مواعيد ثابتة يوميًا في الاتجاهين. الأتوبيس ميني باص. عدد الأتوبيسات والكراسي لسه مش معروف ← ترتيب الكراسي يتعمل configurable، والديمو يشتغل بترتيب افتراضي. |
| 5 | الدفع | إنستا باي فقط، والتأكيد يدوي من المكتب. محدش بيدفع للسواق. الكرسي يتحجز مؤقتًا لحد ما الدفع يتأكد. |
| 6 | حساب الراكب | مفيش حساب. الراكب يكتب اسمه ورقمه بس. كل حجز ليه لينك فيه كود سري طويل، واللينك ده هو المفتاح: منه يشوف التذكرة ويلغي. مفيش صفحة "حجوزاتي" بالتليفون، لأن أي حد كان هيقدر يكتب رقم غيره ويلغيله. لو ضيّع اللينك يكلم المكتب. كود الواتساب أو SMS يتضاف بعد الـ MVP. |
| 7 | الإلغاء | المكتب والراكب الاتنين يقدروا يلغوا. الفلوس بترجع يدوي. |
| 8 | حجز المكتب | الموظف يقدر يحجز من السيستم للي بيتصل. ممكن تتلغي بعدين. |

## التقني

| # | الموضوع | القرار |
|---|---|---|
| 11 | الواجهة | موقع ويب واحد بـ ASP.NET Core Razor Pages، مش تطبيق موبايل. جزء للراكب من غير تسجيل دخول، وجزء للمكتب بتسجيل دخول. منطق الحجز في class library منفصلة عشان API أو تطبيق بعدين يستخدم نفس المنطق. تطبيق أندرويد للسواق بييجي بس مع التتبع. |
| 12 | الاستضافة | لوكال على جهاز المطور. |
| 13 | الفريق | مطور واحد. التنفيذ يبدأ بعد الاتفاق على كل النقط المفتوحة. |
| 14 | اللغة | عربي وإنجليزي بزرار تبديل في الهيدر، والموقع كله (صفحات الراكب ولوحة المكتب ورسايل الأخطاء). العربي هو الافتراضي، والاختيار بيتحفظ في cookie. النص العربي في الكود هو مفتاح الترجمة، والإنجليزي في `Resources/SharedResource.en.resx`، وفيه تيست بيفشل لو نص من غير ترجمة. البيانات اللي المكتب بيكتبها (أسماء المحطات والسواقين) بتظهر زي ما اتكتبت. |
| 14a | الأسرار | باسورد الداتابيز وباسورد يوزر المكتب في `dotnet user-secrets`، مش في `appsettings`. |
| — | الـ Backend | ‎.NET 10 (LTS، الموجود على الجهاز، و‎.NET 8 الدعم بتاعه بيخلص نوفمبر 2026) + PostgreSQL 18 على port 5432. |
| — | منع الحجز المزدوج | unique index جزئي في الداتابيز على (الرحلة، رقم الكرسي) WHERE IsActive — مش check في الكود. الـ check في الكود موجود بس عشان رسالة واضحة. |

## الـ Architecture

نفس هيكل MechanicShop: `Domain` / `Application` (MediatR + FluentValidation، Features/Commands|Queries) / `Infrastructure` / `Web`، والتيستات `Domain.UnitTests` / `Application.UnitTests` / `Application.SubcutaneousTests` / `Tests.Common`.

| اللي اتغير عن MechanicShop | السبب |
|---|---|
| `Web` بـ Razor Pages بدل `Api` + Blazor، ومفيش `Contracts` | قرار 11. الـ Contracts وظيفتها تشارك DTOs بين API و client، ومفيش الاتنين. |
| Cookie auth بـ Identity بدل JWT | Razor Pages. |
| Postgres بدل SQL Server، و Migrations بدل `EnsureCreated` | `EnsureCreated` ما بيعرفش يعدّل الجداول بعد ما تتعمل. |
| تيستات الداتابيز على `sbus_tests` لوكال بدل Testcontainers | Docker مش شغال على الجهاز. التيستات بتعمل skip لو مفيش باسورد. |
| مفيش `CachingBehavior` ولا HybridCache | الكراسي الفاضية بتتغير كل دقيقة. الكاش هيعرض كرسي فاضي وهو محجوز. |
| Logging و Performance behaviours بيسجلوا اسم الـ request والوقت واليوزر بس، مش `{@Request}` | الـ request فيه اسم الراكب وموبايله. |
| Serilog على console وملف بس. مفيش Seq و OpenTelemetry و Scalar و API versioning | ديمو لوكال من غير API. |
| MediatR 12.5.0 | آخر نسخة Apache-2.0. من 13 وطالع محتاجة رخصة تجارية. |
| Rate limiting على الـ POST في صفحات الحجز والتذكرة (10 كل 10 دقايق لكل IP) | من غيره أي script يحجز كل الكراسي كل 15 دقيقة. |

## قرارات اتاخدت أثناء البناء

| الموضوع | القرار |
|---|---|
| رفع التحويل بعد ما الـ 15 دقيقة تخلص | مقبول طالما الـ job لسه ما قفلش الحجز (الحالة لسه "مستني التحويل"). الحالة هي المرجع، مش الساعة، عشان راكب حوّل فعلًا ما يخسرش كرسيه بسبب ثواني. |
| انتهاء الحجز المؤقت | job كل دقيقة، وكمان قبل أي حجز جديد على نفس الرحلة بتتقفل الحجوزات المنتهية فيها، فالكرسي بيفضى فورًا. |
| صورة التحويل | لازم تكون JPG / PNG / WEBP / PDF، والنوع بيتعرف من محتوى الملف مش من الامتداد. أقصى حجم 5 ميجا. بتتخزن برا `wwwroot` باسم عشوائي، وبتتفتح من لوحة المكتب بس. |
| رقم الموبايل | موبايل مصري بس (010 / 011 / 012 / 015)، وبيقبل +20 والأرقام العربي ويحولها لـ 01xxxxxxxxx. |
| تعديل ميعاد | التعديل بيتطبق على الرحلات الجاية اللي مفيهاش حجوزات. الرحلات اللي فيها حجوزات بتفضل زي ما هي، والمكتب بيتبلغ بعددها. |
| إيقاف ميعاد | رحلاته بتختفي من الحجز أونلاين، والحجوزات الموجودة بتفضل. المكتب لسه يقدر يحجز فيها. |
| شكل الكراسي | مينفعش يتعدل بعد ما يتحفظ، عشان الحجوزات مربوطة بأرقام كراسيه. تغيير أتوبيس لشكل تاني بيترفض لو فيه كرسي محجوز مش موجود في الشكل الجديد. |
| رقم السواق | بيظهر للراكب بس بعد ما الحجز يتأكد. |
| الأوقات | بتتخزن UTC وبتتعرض بتوقيت القاهرة (فيه توقيت صيفي). |
